# 🔗 Interactive Linked List in C 

Небольшое интерактивное консольное приложение на языке **C** для работы со связным списком. 🚀 

## ✨ Возможности (Features)

Программа предоставляет удобное консольное меню со следующими функциями:

* 👁️ **View:** Просмотр текущего состояния списка.
* ➕ **Insert:** Добавление новых элементов (в начало `HEAD` или конец `TAIL` списка).
* 🗑️ **Delete:** Удаление всех узлов, которые содержат заданное значение.
* 🔄 **Sort:** Сортировка элементов списка (по возрастанию или убыванию).
* 🔍 **Search:** Поиск элемента по значению.
* 🪄 **Special Function:** Кастомная функция обработки (удаление элементов со значением больше веденного).

## 🛠️ Сборка и запуск

Для компиляции программы вам понадобится `gcc` (или любой другой компилятор C). 

Выполните в терминале следующие команды:

```bash
# Компиляция программы (убедитесь, что linked_list.c тоже в папке)
gcc main.c linked_list.c -o linked_list_app

# Запуск
./linked_list_app
